# Workflow Git

## État observé

Le dépôt ne fournit pas d’information explicite sur les branches, PR ou conventions de commit.

## Workflow recommandé

- `main` pour la branche de production,
- `develop` pour la branche de travail si nécessaire,
- branches thématiques pour les évolutions,
- PR avec revue avant fusion,
- commits clairs avec messages structurés,
- tags pour les versions de production.

## Convention recommandée

- `feat:` pour une nouvelle fonctionnalité,
- `fix:` pour un correctif,
- `docs:` pour la documentation,
- `refactor:` pour la refonte technique,
- `test:` pour les tests,
- `chore:` pour les tâches de maintenance,
- `security:` pour les correctifs de sécurité.
