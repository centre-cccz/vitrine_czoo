# Processus de release

## Processus recommandé

1. valider la branche de travail,
2. revoir le diff technique et fonctionnel,
3. vérifier les dépendances et les impacts,
4. publier la version sur l’environnement défini,
5. valider le site ou l’application,
6. documenter le changelog et les impacts,
7. préparer le rollback si nécessaire.

## À confirmer

- mécanisme exact de publication,
- environnement de validation,
- procédure de validation par le Centre.
