# Normes de codage

## Principes

- garder le code lisible,
- documenter les éléments de logique non triviaux,
- éviter les raccourcis de sécurité,
- conserver une séparation claire des responsabilités,
- respecter la simplicité avant la complexité.

## Standards applicables

- HTML sémantique et accessible,
- CSS lisible et structuré,
- JS sans duplication inutile,
- validation serveur obligatoire,
- nommage clair des variables et fonctions,
- commentaires uniquement si nécessaires.
