# Résolution des incidents

## Cas fréquents

- page non affichée : vérifier le serveur web et les chemins de fichiers,
- formulaire de contact non fonctionnel : vérifier PHP, base MySQL et configuration mail,
- erreur de base de données : vérifier la connexion et le schéma,
- CSS ou JS non chargés : vérifier les chemins et les dépendances CDN,
- erreur de permissions : vérifier les fichiers du serveur.

## Bonnes pratiques

- conserver des logs de service,
- tenir un journal des incidents,
- documenter les correctifs,
- valider immédiatement après tout déploiement.
