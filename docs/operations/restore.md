# Restauration

## Processus recommandé

1. arrêter les écrans d’administration si nécessaire,
2. restaurer la base de données depuis le dernier backup valide,
3. restaurer les fichiers du site,
4. vérifier les permissions et la configuration,
5. valider les pages clés,
6. relancer les services ou le serveur web.

## À confirmer

Le processus exact dépend du fournisseur d’hébergement et des outils utilisés par le Centre. Les procédures concrètes doivent être documentées côté infrastructure réelle.
