# Monitoring

## À surveiller

- disponibilité du site public,
- erreurs PHP / JavaScript,
- réactivité du serveur,
- logs des demandes de contact,
- erreur de base de données,
- uptime du site,
- disponibilité des services externes.

## Indicateurs recommandés

- uptime,
- error rate,
- tempo de réponse,
- taux d’échec des formulaires,
- temps de chargement des pages,
- présence de erreurs de base de données,
- nombre de demandes de contact.

## Remarque

Aucun outil de monitoring n’est observé dans le dépôt. Le Centre doit confirmer la solution réellement utilisée.
