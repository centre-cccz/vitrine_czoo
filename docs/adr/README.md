# ADR – Architecture Decision Records

Les ADR servent à documenter les décisions architecturales importantes et les raisons qui les sous-tendent.

## Règles

- documenter uniquement les décisions à fort impact,
- distinguer l’existant de la cible,
- expliquer le contexte et les alternatives,
- mettre à jour si la décision évolue.

## ADR en vigueur

- Aucun ADR n’a été formellement adopté dans le dépôt à ce stade.
- Un modèle de base est fourni dans `ADR-0001-template.md`.

## Décisions à surveiller

- séparation du site public et de la Gestion interne,
- choix éventuel du backend,
- décision sur le stockage de données,
- stratégie d’authentification,
- stratégie de déploiement.
