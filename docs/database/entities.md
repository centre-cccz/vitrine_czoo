- identifiant

- email
- rôle
- service
- statut

### Événement

- identifiant
- titre
- catégorie
- description
- date
début / fin
- lieu
- image
- statut (brouillon / publié / archive)

### Artiste

- identifiant
- nom
- spécialité
- bio
- visuels
- statut

### Espace

- identifiant
- nom
- fonction
- description
- type

### Partenaire

- identifiant
- nom
- type de partenariat
- statut
- contact principal

### Demande / contact

- source
- type
- objet
- statut
- date
