# RFC – Request for Comments

Le système RFC permet de formaliser les changements structurants du projet avant leur mise en œuvre.

## Quand utiliser une RFC

- nouveau module majeur,
- changement de base de données,
- changement d’architecture,
- nouveau fournisseur,
- nouvelle stratégie d’authentification,
- modification importante de la CI/CD ou du déploiement.

## Modèle

Le template est disponible dans `RFC-0001-template.md`.

## Règle

Une RFC ne doit pas être utilisée pour des changements mineurs ou stylistiques. Elle est réservée aux évolutions à forte incidence technique ou organisationnelle.
